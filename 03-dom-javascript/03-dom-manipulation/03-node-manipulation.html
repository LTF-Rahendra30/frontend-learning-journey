DOM Node Manipulation Methods

1️⃣ parentNode.append() — Tambah ke Akhir

2️⃣ parentNode.prepend() — Tambah ke Awal

3️⃣ childNode.before() — Sisipkan Sebelum Node

4️⃣ childNode.after() — Sisipkan Sesudah Node

5️⃣ childNode.remove() — Hapus Node dari DOM

6️⃣ childNode.replaceWith() — Ganti Node dengan Node Lain
